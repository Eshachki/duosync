# DuoSync

Синхронизатор одного Unity-проекта между двумя компьютерами через GitHub. У одного участника («сводящий») есть Claude Code, он решает конфликты. У второго нейросети в программе нет, его спорные изменения уходят на слияние первому.

## Где что
- Архитектура, решения и заметки лежат локально в `docs/private/` и в git не идут, потому что репозиторий публичный:
  - `DuoSync-архитектура.md` — полная архитектура, читай только нужный раздел;
  - `decisions.md` — решения по итогам проверок, главнее архитектуры;
  - `NOTES.md` — люди, пути, лаборатории, как обновить установленную копию.
- §2.4 архитектуры (ADR-000) — список того, чего в системе нет. Любую новую функцию сначала сверяй с ним.
- `src/DuoSync.Core` — логика без UI: git, снимки, Apply, слияние, состояние, подготовка проекта, клиент моста.
- `src/DuoSync` — WinForms: трей, окно, самоустановка, автозапуск, `--cli`.
- `tests/DuoSync.Core.Tests` — xUnit, сценарные тесты: bare-remote и два клона.
- `bridge/com.duosync.bridge` — Editor-only UPM-пакет для Unity. Он вшит в программу и ставится в проект при подготовке. `.meta` в формате Unity 6 с постоянными GUID.

## Команды
- Сборка: `dotnet build DuoSync.slnx`
- Тесты: `dotnet test DuoSync.slnx`
- Отладка на папке проекта: `DuoSync.exe --cli prepare|receive|send|undo|status|unity <папка>`

## Правила
- Репозиторий публичный. В коде, тестах и коммитах не должно быть секретов, адресов и путей серверов, ключей, личных имён и названий приватных проектов. Фикстуры тестов только синтетические.
- Git программа вызывает только через GitRunner. Критичные настройки передаются через `-c`, вывод разбирается только в машинных форматах (`-z`, porcelain v2).
- Программа коммитит и пушит только по кнопкам человека. Автокоммитов, автопуша и автослияния нет.
- Рабочую папку меняет только `Applier.ApplyAsync`: журнал, проверка после checkout, откат при сбое.
- Тексты интерфейса и уведомлений — на русском. Имена людей в сообщениях ставятся только в именительном падеже.
- Мост в Unity работает только через `EditorApplication.update` и не запускается в процессах импорта и в пакетном режиме.

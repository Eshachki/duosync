# DuoSync

Программа для Windows, которая синхронизирует один Unity-проект между двумя компьютерами через GitHub. Отправка и получение идут по кнопкам, об обновах друга приходят уведомления, конфликты разбирает Claude.

Статус: в разработке.

## Сборка

Нужен .NET SDK 10.

```
dotnet build DuoSync.slnx
dotnet test DuoSync.slnx
```

# DuoSync

Программа для Windows, которая синхронизирует один Unity-проект между двумя компьютерами через GitHub. Отправка и получение идут по кнопкам, об обновах друга приходят уведомления, конфликты разбирает Claude.

Статус: в разработке.

## Установка

Скачать [DuoSync.exe](https://github.com/Eshachki/duosync/releases/latest/download/DuoSync.exe) и запустить. Программа сама встанет в `%LOCALAPPDATA%\DuoSync`, пропишется в автозапуск и дальше будет обновляться сама. Нужны git и git-lfs, вход в GitHub — тот же, что у git.

Проект, который создал один из вас, у второго появится сам: уведомление «Новый проект» и кнопка «Скачать».

## Сборка

Нужен .NET SDK 10.

```
dotnet build DuoSync.slnx
dotnet test DuoSync.slnx
```
